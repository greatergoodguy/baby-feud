Official / real Family Feud clips (PRIVATE — never committed)
============================================================
Files in this folder are gitignored, so they are NOT pushed to GitHub and
NOT on the public site. Use this for the actual show audio, for private play.

Name them (first match wins), .mp3 / .ogg / .wav:
  correct.mp3   (or ding.mp3 / right.mp3)
  strike.mp3    (or buzzer.mp3 / wrong.mp3)
  win.mp3       (or applause.mp3 / fanfare.mp3)

These OVERRIDE both the built-in sounds and anything in ../ (audio/).

Note: for these to play on the TV at the party, run the board from a copy
that has these files (double-click index.html, or serve this folder locally).
The public github.io URL will not have them (by design) and uses the
royalty-free / built-in sounds instead.

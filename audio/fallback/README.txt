Fallback sound effects (PUBLIC / committed)
===========================================
Put ROYALTY-FREE / CC0 clips here. These DO get pushed to GitHub and play on
the public site, and they also play locally whenever audio/official/ is empty.
Only use clips you're allowed to host publicly (NOT the copyrighted show audio
— that goes in ../official/, which is gitignored).

Name them (first match wins), .mp3 / .ogg / .wav:
  correct.mp3   (or ding.mp3 / right.mp3)   -> answer revealed
  strike.mp3    (or buzzer.mp3 / wrong.mp3) -> a strike
  win.mp3       (or applause.mp3 / fanfare.mp3) -> win screen

No files here? The game uses its built-in synth sounds.

Remember to commit + push after adding files, so the live site picks them up.
